# Onifade Timileyin Ayodeji — UI/UX Portfolio

A responsive, static portfolio website built with HTML, CSS, and JavaScript.

## Included
- Dark, modern visual direction with violet and teal accents
- Responsive navigation and project filters
- Seven project overviews with clickable case-study dialogs
- Supplied project screenshots stored in `assets/`
- Contact links for email, phone, LinkedIn, and Instagram
- Accessibility basics: skip link, descriptive image alt text, keyboard-accessible buttons, reduced-motion support

## Projects represented
1. TumzyTech — personal AI technology website concept
2. AgroGrow — agritech product concept (illustrative portfolio preview)
3. Damco Properties — real estate homepage concept
4. E-Shop storefront — e-commerce concept
5. Watch Storefront — luxury retail interface exercise
6. Internship Landing Page — internship work (illustrative preview until original screenshot is supplied)
7. Real Estate Landing Page — UI challenge, Day 04
8. Welcome, Sign-up & Login — authentication UI exercise
9. Fitness & Activity App — UI challenge, Day 02

The case-study copy intentionally distinguishes design concepts and classroom/UI challenge work from live products. Placeholder prices, statistics, and activity metrics in source designs are not represented as verified facts.

## Run locally
Open `index.html` in a browser. For best results, use a local static server or deploy the folder to a static host such as GitHub Pages or Vercel.

## Edit
- Main page: `index.html`
- Styling: `styles.css`
- Case-study text and interactions: `script.js`
- Images: `assets/`
